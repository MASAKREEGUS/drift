# t01 — statistics of integers

Read integers from standard input. They are separated by any amount of whitespace (spaces, tabs, newlines).
An integer is an optional `-` followed by one or more ASCII digits (`+5`, `3.5`, `1e3`, `abc` are not integers).
Values satisfy |x| ≤ 10^9 and there are at most 10^6 of them.

Print exactly four lines:

```
min <smallest value>
max <largest value>
mean <arithmetic mean, exactly 2 decimals>
median <median>
```

- `mean`: rounded to 2 decimals (the exact mean is never halfway between two 2-decimal numbers, and is never in (-0.005, 0)).
- `median`: for an odd count, the middle value of the sorted list; for an even count, the mean of the two middle values,
  printed as an integer when it is whole and otherwise with one decimal (it then always ends in `.5`, e.g. `-3.5`).

Errors: if the input contains no integers, or any token that is not an integer, print a message to standard error and
exit with status 1 (standard output is not checked in that case).

Example: input `3 1 4 1 5` prints `min 1`, `max 5`, `mean 2.80`, `median 3`.
