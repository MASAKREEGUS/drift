# t02 — Roman numerals

Each line of standard input is converted independently and produces one output line. Before converting, remove
spaces, tabs and carriage returns (`\r`) from both ends of the line; lines that are then empty are skipped and
produce no output.

- A line made only of ASCII digits `0`-`9` is a decimal number. If it is between 1 and 3999 and has no leading zero,
  print its Roman numeral; otherwise print `invalid`.
- Any other line must be a Roman numeral in canonical form: uppercase `I V X L C D M`, written with the standard
  subtractive pairs only (`IV IX XL XC CD CM`), values 1 to 3999, the same way the decimal → Roman direction writes
  them. Print its value in decimal, or `invalid` if it is not canonical.

Canonical means the numeral is exactly what converting its value back would print: `IIII`, `VV`, `IL`, `IC`, `XM`,
`MMMM`, `iv` (lowercase), `X I` (inner space) and `Ⅻ` (Unicode roman numeral characters) are all `invalid`.
Digits other than ASCII `0`-`9` (for example Arabic-Indic `١٢`) do not form a decimal number, and are not Roman
numerals either.

The exit status is always 0. The input has at most 10^6 lines.

Example:
```
14          → XIV
MCMXCIV     → 1994
  3999      → MMMCMXCIX
IIII        → invalid
0           → invalid
007         → invalid
```
