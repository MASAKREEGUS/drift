# t06 — expression evaluator

Each line of standard input is an integer expression. Lines that are empty or only spaces/tabs are skipped; every
other line produces one output line: the value, or an error `error at <column>: <message>`.

Grammar (usual precedence, left associative):
```
expr    := term (('+' | '-') term)*
term    := unary (('*' | '/' | '%') unary)*
unary   := '-' unary | primary
primary := INTEGER | '(' expr ')'
```
INTEGER is one or more ASCII digits (at most 10^18). Spaces and tabs may appear between tokens.
`/` truncates toward zero and `%` has the sign of the dividend (as in C): `-7 / 2` is `-3`, `-7 % 2` is `-1`.
No test overflows signed 64-bit integers, in the result or in any intermediate value.

Columns count characters (Unicode code points, not bytes) from 1. Errors, checked in this order:
1. `unexpected character` — the first character that is not a digit, space, tab or one of `+ - * / % ( )`.
2. A syntax error, found by parsing the whole line left to right:
   `unexpected token` at the first token that can't continue the expression, or
   `unexpected end` when the line ends too early (column = number of characters in the line + 1).
3. `division by zero` at the column of the `/` or `%` operator. Evaluate operands before their operator and the left
   operand before the right one; report the first division by zero met in that order.

Examples:
```
1 + 2 * 3        → 7
(1 + 2) * -3     → -9
7 / -2           → -3
2 * (3 + 4       → error at 11: unexpected end
1 + * 2          → error at 5: unexpected token
4 / (2 - 2)      → error at 3: division by zero
1 + ñ            → error at 5: unexpected character
```
