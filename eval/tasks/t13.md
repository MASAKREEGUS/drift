# t13 — sudoku

Each line of standard input is a puzzle: 81 characters, row by row, `1`-`9` for givens and `.` or `0` for empty cells.
For each line print one line:
- the solved grid as 81 digits, if the puzzle has a solution (tests only contain puzzles with at most one solution);
- `no solution` if it has none (including puzzles whose givens already conflict);
- `invalid` if the line does not have exactly 81 characters or contains another character.

Some puzzles are very hard for naive backtracking; there can be a few hundred puzzles in one input. Run time is measured.
