# t12 — topological sort with cycle detection

Each non-blank line of standard input is either `<a> -> <b>` (a must come before b; spaces around `->` are optional
and may be several) or a single `<a>` (declares a node). Names match `[A-Za-z0-9_]+`. Duplicate edges may appear.

Print every node once, one per line, in an order where a comes before b for every edge. Whenever several nodes could
come next, print the smallest name first, comparing names by bytes (so `B` < `a`, `a1` < `a_`). Exit status 0.

If the edges contain a cycle, print instead one line `cycle: x1 -> x2 -> ... -> xk -> x1` naming any cycle (distinct
nodes, each `->` is an edge of the input; a self-loop is `cycle: a -> a`) and exit with status 1.

Example: lines `shirt -> tie`, `tie -> jacket`, `pants -> shoes`, `socks` print `pants`, `shirt`, `shoes`, `socks`,
`tie`, `jacket`.
