# t03 — word frequency

Usage: `program N`, where N is a positive integer (the first command-line argument).
Read UTF-8 text from standard input. A *word* is a maximal run of characters whose Unicode general category is a
letter (Lu, Ll, Lt, Lm, Lo) or a number (Nd, Nl, No). Everything else separates words (so `don't` is `don` and `t`).
Words are compared after full Unicode lowercasing of the word (as Python's `str.lower`: `Straße` → `straße`,
`ÑANDÚ` → `ñandú`, Greek capital sigma at the end of a word → `ς`).

Print the N most frequent words, one per line as `<count> <word>`, by count descending and, for equal counts, by word
ascending in Unicode code point order. If there are fewer than N distinct words print all of them.

Errors: N missing or not a positive integer → message on standard error, exit status 2.

Example: `printf 'b a B a, c' | program 2` prints `2 a` and `2 b`.
