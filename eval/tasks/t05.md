# t05 — CSV to JSON

Read CSV from standard input and print it as a JSON array of objects.

CSV rules (RFC 4180):
- Fields are separated by `,` and records end with `\n` or `\r\n`. A line break at the very end of the input does not
  start a new record.
- A field may be enclosed in double quotes. Inside a quoted field, `""` is one literal `"`, and commas, `\n` and `\r\n`
  are literal parts of the value.
- The first record is the header (its names are distinct). Every other record becomes one object that maps each
  header name to the field value, in header order. All values are JSON strings.
- Empty input, or a header with no data records, prints `[]`.

Errors — print a message to standard error and exit with status 1 (standard output is not checked):
- a record whose number of fields differs from the header's,
- an unterminated quoted field,
- a `"` inside an unquoted field, or anything other than `,`, a line break or the end of input right after a closing quote.

Output is compared as JSON (whitespace and key layout don't matter); the text is UTF-8 and may contain any characters.

Example: input `name,note\nAna,"says ""hi"", twice"\n` prints `[{"name":"Ana","note":"says \"hi\", twice"}]`.
