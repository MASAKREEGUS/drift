# t10 — shortest path

Standard input: the first line is `n m` (1 ≤ n ≤ 200000, 0 ≤ m ≤ 1000000). Each of the next m lines is `u v w`: a
directed edge from node u to node v (0 ≤ u, v < n) with weight 1 ≤ w ≤ 10^9. Parallel edges and self-loops may appear.
The last line is `s t`.

If t is not reachable from s print `no path`. Otherwise print two lines:
```
cost <total weight of the shortest path from s to t>
path <s> <next node> ... <t>
```
Tests guarantee the shortest path is unique. When s = t the cost is 0 and the path is just `s`.
Large inputs are part of the tests (about 20 MB), so read input efficiently; run time is measured.

Example: input
```
3 3
0 1 5
1 2 1
0 2 10
0 2
```
prints `cost 6` and `path 0 1 2`.
