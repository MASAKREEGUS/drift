# t08 — sales by store and month

Standard input is a CSV file of sales. Lines end with `\n` (a `\r` before it is removed). The first line must be
exactly `date,store,amount`; if it is not (or the input is empty), print a message to standard error and exit with
status 1. Empty lines are skipped. Every other line is a record, split on `,` with no quoting.

A record is valid when it has exactly 3 fields and:
- `date` is `YYYY-MM-DD` with ASCII digits and is a real calendar date (Gregorian, leap years included, year 0001-9999);
- `store` is not empty (it is used exactly as written: case, spaces and any Unicode characters matter);
- `amount` is an optional `-`, 1 to 9 ASCII digits, then optionally `.` and 1 or 2 digits: `12`, `12.5`, `-3.05`.
  (`+1`, `.5`, `1.`, `1.234`, `1e3`, `1,5` are invalid.) Negative amounts are refunds.

Invalid records are counted and otherwise ignored.

Output one line per (store, month) that has at least one valid record:
```
<store>,<YYYY-MM>,<total>,<count>
```
sorted by store (by Unicode code point, i.e. byte order of the UTF-8 text) and then by month. `total` is the exact
sum of the amounts of that group with exactly 2 decimals (`1234.50`, `-0.05`, `0.00`; never `-0.00`); `count` is the
number of records in the group. After the groups print one last line `invalid <number of invalid records>`.
Exit status 0. There are at most 10^6 records; every total fits easily in 64-bit integer cents.

Example input:
```
date,store,amount
2026-01-15,Lider,10.50
2026-01-20,Lider,-0.5
2026-02-01,Jumbo,3
2026-02-30,Jumbo,1.00
2026-01-31,Jumbo,2.25
```
Output:
```
Jumbo,2026-01,2.25,1
Jumbo,2026-02,3.00,1
Lider,2026-01,10.00,2
invalid 1
```
